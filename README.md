# Residencia Universitaria Viña del Mar — Web & Propuestas 2027

Este repositorio contiene la página web oficial y las propuestas digitales para la Residencia Universitaria Viña del Mar (Paseo Valle 387).

## Contenido del Repositorio:
- `index.html`: Página web completa 100% responsiva y optimizada para SEO.
- `assets/`: Carpeta con todas las imágenes de las instalaciones y conectividad universitaria.
- `propuesta-digital-residencia-vina-2027.pdf`: Propuesta Digital Estratégica 2026-2027.
- `plan-operativo-canalizacion-web-paxer.pdf`: Plan Operativo Técnico de Canalización y Paxer + WhatsApp 24/7.

## Instrucciones para publicar en GitHub Pages:
1. Sube todos los archivos de esta carpeta a tu repositorio en GitHub.
2. Ve a la pestaña **Settings** (Configuración) de tu repositorio.
3. En el menú de la izquierda, selecciona **Pages**.
4. En **Build and deployment > Source**, selecciona `Deploy from a branch`.
5. Elige la rama `main` (o `master`) y la carpeta `/ (root)` y presiona **Save**.
6. En un par de minutos, GitHub te entregará el enlace público funcional con imágenes cargadas.
